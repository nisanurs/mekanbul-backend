# Mekanbul Backend API

This project is a RESTful API developed using Node.js and Express.  
It provides location-based venue data and handles backend logic for the Mekanbul web application.

## Features

- REST API architecture
- Location-based venue listing
- JSON data responses
- CRUD operations
- Error handling & routing structure

## Technologies Used

- Node.js
- Express.js
- MongoDB (if used)
- Mongoose (if used)

## Project Structure

- `app.js` – Main application file
- `routes/` – API route definitions
- `controllers/` – Business logic
- `models/` – Database models
- `config/` – Configuration files
